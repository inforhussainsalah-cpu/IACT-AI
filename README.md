# IACT-AI

IACT-AI is an evidence-governed, IACT-inspired AI research and engineering architecture.

## Mission

Enhancing Scientific and Academic Capability through evidence-grounded reasoning, problem solving, research assistance, controlled tool use, evaluation, and human-supervised improvement.

## Scientific Status

IACT-AI is currently an engineering and research prototype.

IACT-AI does not claim that IACT has been scientifically established.

## Core Architecture

UNDERSTAND
→ RETRIEVE
→ VERIFY
→ ASSOCIATE
→ TRANSLATE
→ GENERATE
→ SIMULATE
→ COMPARE
→ TEST
→ GOVERN
→ RESPOND / ACT
→ MEASURE
→ UPDATE

## Evidence Principle

CLAIM STRENGTH <= EVIDENCE STRENGTH

### Evidence Levels

E0 = Conceptual proposition

E1 = Operationalized hypothesis

E2 = Pilot / feasibility evidence

E3 = Confirmatory support under defined conditions

E4 = Compatible replication

E5 = Independent validation

## Governance

IACT-AI uses four decision states:

🟢 PASS

🟡 REVIEW

🔴 RESTRICT

⚫ UNKNOWN

Governance evaluates:

- Scientific integrity
- Ethical considerations
- Applicable law
- Human rights
- Privacy
- Security
- Safety
- Fairness
- Impact
- Foreseeable misuse
- Residual risk
- Uncertainty

## Permission Architecture

L0 = READ

L1 = CREATE

L2 = PROPOSE

L3 = ACT

L4 = HIGH-IMPACT ACTION

Knowledge does not automatically grant permission to act.

## No Self-Approval

IACT-AI must not independently propose, approve, and deploy a high-impact permanent system change.

## Controlled Improvement

OBSERVED WEAKNESS
→ CANDIDATE IMPROVEMENT
→ TEST
→ GOVERNANCE REVIEW
→ INDEPENDENT EVALUATION
→ HUMAN REVIEW
→ SANDBOX
→ LIMITED DEPLOYMENT
→ MONITOR
→ KEEP / REVISE / ROLLBACK

- Evidence module
- Candidate reasoning
- Governance module
- Audit records
- PASS / REVIEW / RESTRICT / UNKNOWN classifications
- L0-L4 permissions
- OpenAPI contract
- Automated tests
- Docker support
- GitHub Actions CI

## Current Limitation

The current implementation is a runnable architecture prototype.

The default model provider is currently a mock implementation.

A real AI model, advanced retrieval, PDF/OCR processing, production storage, production identity/security, and independent TEVV require further implementation and validation.
